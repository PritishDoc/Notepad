# Notepad Internal Frame

## Overview

The Notepad Internal Frame project is a simple Java-based text editor implemented using the Swing library. It provides basic functionalities such as opening, editing, and saving text files within an internal frame.

## Features

- **Open Files**: Allows users to open and read text files.
- **Save Files**: Enables users to save their text content to a file.
- **Exit Application**: Closes the notepad application.

## Project Structure

- `NotepadInternalFrame.java`: The main class that extends `JInternalFrame` and implements the notepad functionalities.

## How to Run

### Prerequisites:

- Ensure you have Java Development Kit (JDK) installed. This project requires JDK 8 or higher.

### Compile the Program:

- Navigate to the directory containing `NotepadInternalFrame.java`.
- Open a terminal or command prompt and run the following command:
  ```sh
  javac NotepadInternalFrame.java
## Usage
**Opening a File**:
- Click on the "File" menu and select "Open".
- Choose the file you want to open from the file chooser dialog.
**Saving a File**:
- Click on the "File" menu and select "Save".
- Choose the destination and filename from the file chooser dialog.
**Exiting the Application**:
Click on the "File" menu and select "Exit" to close the application.
